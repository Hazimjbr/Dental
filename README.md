# Dental MCQs Platform 🦷
An interactive Telegram Bot and Channel Automation Platform for Dental Board Exams (ORE, MFDs, MJDF).

## Features
- **910 MCQ Database** with full explanations and categorization.
- **Option Shuffling** dynamically.
- **Weekly Progress Reports** for students.
- **Review mistakes deck** (`🔴 My Mistakes`).
- **Clinical pearls** posted daily to the channel.
